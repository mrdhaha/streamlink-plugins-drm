# streamlink-plugins-drm
Streamlink plugins for sites with DRM-protected media

## Dependencies
You will need to sideload the following additional plugins:
- [widevine.py](https://github.com/its-wizza/streamlink-plugin-widevine)
- [dashdrm.py](https://github.com/its-wizza/streamlink-plugin-dashdrm/tree/local-combined)
- [hlsdrm.py](https://github.com/its-wizza/streamlink-plugin-hlsdrm/tree/support-kid-matching)
